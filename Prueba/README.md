# Kivy Color App

Aplicación de escritorio hecha con **Python y Kivy** que muestra colores y paletas usando la API de [The Color API](https://www.thecolorapi.com/).

## Funcionalidades
- Ingresar un color en formato HEX.
- Mostrar el color principal y una paleta relacionada.
- Seleccionar modos: Análogico, Monocromático, Complementario, Tríada y Cuarteto.
- Interfaz moderna y responsiva.
